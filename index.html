Les classes d’adresses

La classe se lit sur le premier octet de l’adresse (de 0 à 255) :

Premier octet de 0 à 255 (la barre est proportionnelle ; le trait gris est 127, le loopback).

127.0.0.0/8 : loopback. 127.0.0.1 désigne toujours votre propre machine (localhost). Cette plage est réservée, c’est pourquoi la classe A s’arrête à 126.
Une notion ancienne. Ce classement (« classful ») n’est plus utilisé tel quel : les réseaux modernes utilisent CIDR, où la longueur du préfixe (/22, /27…) est choisie librement, quel que soit le premier octet. Exemple : 192.168.1.0/26 est un réseau de 64 adresses, même si l’adresse « ressemble » à la classe C.

Adresses privées et publiques

Les adresses privées (RFC 1918) servent dans les réseaux locaux (maison, entreprise). Elles ne sont pas routées sur Internet : le routeur ou la box utilise le NAT pour faire sortir les machines derrière une adresse publique. Des réseaux différents peuvent donc réutiliser les mêmes adresses privées.

Adresse publique : elle n’appartient à aucune de ces plages privées ; elle peut être routée sur Internet et est unique dans le monde. Attention, non privée ne veut pas toujours dire publique : d’autres plages sont réservées (127.0.0.0/8, 169.254.0.0/16, 100.64.0.0/10, 224.0.0.0/4, 240.0.0.0/4…).
